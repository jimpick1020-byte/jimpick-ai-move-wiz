# 짐픽 전용 물체 분할 모델 자리

이 폴더에 아래 파일을 넣으면 사진 속 가구·가전의 **실제 외곽선**(소파 팔걸이, 침대 모서리, 캣타워 발판까지)이 표시됩니다.
파일이 없으면 앱은 가짜 외곽선을 만들지 않고, 기존 네모 상자 표시 + "정밀 외곽선 처리 중" 안내를 유지합니다.

| 파일 | 설명 | 필수 |
| --- | --- | --- |
| `jimpick-furniture-seg.onnx` | Instance Segmentation 모델 (YOLOv8-seg 형식 출력: `[1, 4+클래스+32, N]` + `[1,32,H,W]`) | 필수 |
| `jimpick-furniture-seg.labels.json` | 클래스 순서대로 영문 라벨 배열 (`["sofa","bed",...]`) | 권장 |

- 실행: `onnxruntime-web` (WebGPU 우선, 미지원 기기는 WASM 자동 전환), 계산은 Web Worker.
- 코드는 분리되어 있어 **이 파일만 교체**하면 전용 학습 모델이 바로 적용됩니다.
- 라벨은 `src/lib/item-aliases.ts` 의 별칭 표를 통해 한글 품목명·기존 품목 ID로 자동 연결됩니다.

## 아직 학습 데이터가 필요한 품목
캣타워, 스타일러(의류관리기), 김치냉장고, 돌침대·흙침대 등 한국 가정 특화 품목은 일반 공개 모델이 잘 구분하지 못합니다.
전용 학습 모델 파일이 준비되기 전까지 이 품목들은 네모 상자 인식으로만 표시됩니다.
