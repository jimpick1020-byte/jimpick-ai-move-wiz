# 부동산 1분 블로그 비서 (Streamlit)

5060 세대 공인중개사를 위한 모바일 최적화 부동산 블로그 초안 생성기입니다.
현장에서 사진을 찍고 아파트 이름과 가격만 입력하면 AI가 블로그 초안을 작성하고,
사장님이 직접 확인·수정한 뒤 발행하는 Human-in-the-loop 흐름으로 동작합니다.

> 참고: 이 앱은 메인 React(JIMPICK) 앱과는 별개로 동작하는 독립 Streamlit 프로토타입입니다.

## 사용 흐름

1. 매물 사진 업로드 (여러 장 가능)
2. 아파트 이름 · 가격/조건 입력
3. "블로그 글 뚝딱 완성하기" 버튼으로 초안 생성
4. 생성된 제목/본문을 확인·수정 후 발행

## 실행 방법

```bash
cd streamlit-blog-generator
pip install -r requirements.txt
streamlit run app.py
```

## 참고

현재 3단계 글 생성과 4단계 발행은 시뮬레이션(더미 텍스트/성공 메시지)입니다.
실제 AI 글쓰기 API나 네이버 블로그 발행 연동은 아직 붙어 있지 않습니다.
