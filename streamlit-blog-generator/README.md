# 부동산 1분 블로그 마케팅 비서 (Streamlit)

5060 세대 공인중개사를 위한 모바일 최적화 **실전 마케팅용** 부동산 블로그 생성기입니다.
현장에서 사진을 찍고 매물 정보만 넣으면 **진짜 AI(Google Gemini)** 가 사진까지 직접 보고
**고객이 당장 연락하고 싶어지는 고품격 블로그 포스팅**을 작성합니다. 소장님이 직접
확인·수정한 뒤, **실제 네이버 블로그로 자동 발행**(사진 자동 삽입 포함)하는
Human-in-the-loop 흐름으로 동작합니다.

> 참고: 이 앱은 메인 React(JIMPICK) 앱과는 별개로 동작하는 독립 Streamlit 프로토타입입니다.

## 주요 기능

- 🌸 **프리미엄 감성 UI** — 화사한 핑크 톤 디자인, 모바일 친화적 레이아웃(설정은 접이식 메뉴로 정리)
- 🧠 **실전 마케팅 글쓰기** — 서론 → 상세 분석(입지·학군·교통·구조) → 추천 대상 → CTA
  구성의 길고 전문적인 글을 Gemini AI가 작성
- 📸 **사진 멀티모달** — 업로드한 매물 사진을 AI가 직접 보고 특징(구조·채광·인테리어·뷰)을 글에 반영
- 🖼️ **사진 위치 자동 배치** — AI가 본문 흐름상 좋은 자리에 `[📸 …]` 안내를 넣으면,
  발행 시 그 자리에 실제 사진이 자동 삽입(대표 사진은 맨 위 고정 + 캡션)
- 📞 **연락처 자동 삽입** — 상호명·담당자·전화번호·**사무소 주소**를 글 맨 아래 문의 블록으로 자동 삽입
- 🚀 **실제 네이버 발행** — 네이버 로그인(OAuth2) + 블로그 글쓰기 API로 진짜 발행
- ✅ **안전장치** — 발행 전 항상 사람이 확인·수정. 키가 없어도 샘플/시뮬레이션으로 앱 구동

## 사용 흐름

1. **1단계** — 매물 사진 업로드 (여러 장, AI가 직접 보고 반영)
2. **2단계** — 아파트 이름 · 가격/조건 · (선택) 추가 강조 포인트 입력
3. **글 생성** — "고품격 블로그 글 뚝딱 완성하기" → AI가 마케팅 글 작성 + 연락처 자동 삽입
4. **3단계** — 완성된 제목/본문 확인·수정 → 네이버 로그인 → **실제 발행**(사진 포함)

## 실행 방법

```bash
cd streamlit-blog-generator
pip install -r requirements.txt
streamlit run app.py
```

실행하면 브라우저에서 `http://localhost:8501` 로 열립니다.
**API 키 없이도 바로 실행**되며(글은 샘플, 발행은 연습 모드), 아래 설정을 넣으면 실기능이 켜집니다.

## 설정 요약

모든 키/정보는 아래 세 곳 중 하나에 넣으면 됩니다. (secrets → 환경변수 → 사이드바 순으로 탐색)

- **secrets 파일** — `.streamlit/secrets.toml.example` 를 `.streamlit/secrets.toml` 로 복사 후 입력
  (이 파일은 `.gitignore`에 등록되어 깃에 올라가지 않습니다.)
- **환경변수** — 아래 표의 이름으로 `export`
- **사이드바** — 앱 왼쪽 사이드바에 직접 입력

| 용도 | secrets / 환경변수 이름 | 발급처 |
|------|------------------------|--------|
| AI 글쓰기 | `GEMINI_API_KEY` (또는 `GOOGLE_API_KEY`) | [Google AI Studio](https://aistudio.google.com/apikey) |
| 네이버 발행 | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `NAVER_REDIRECT_URI` | [네이버 개발자센터](https://developers.naver.com) |
| 사진 자동 삽입 | `IMGBB_API_KEY` | [imgbb API](https://api.imgbb.com/) |

> 중개사무소 정보(상호명·담당자·연락처)는 사이드바에서 입력하며, 글 맨 아래 문의 블록으로 자동 삽입됩니다.

사용 모델은 `app.py` 상단의 `GEMINI_MODEL` 값(기본 `gemini-2.5-flash`)에서 바꿀 수 있습니다.

## 네이버 블로그 발행 설정

발행은 **네이버 로그인(OAuth2) + 블로그 글쓰기 API** 로 실제 동작합니다.

1. [네이버 개발자센터](https://developers.naver.com)에서 애플리케이션을 등록합니다.
2. 사용 API에 **네이버 로그인**과 **블로그**(글쓰기)를 추가합니다.
3. 로그인 콜백(Callback) URL에 앱이 실행되는 주소를 등록합니다. (로컬은 보통 `http://localhost:8501`)
4. 발급받은 `Client ID` / `Client Secret` / `Redirect URI` 를 위 방법 중 하나로 입력합니다.

### 발행 흐름

1. 완성된 글을 확인·수정합니다. (연락처 블록이 자동 포함되어 있습니다)
2. **네이버 로그인** 버튼으로 본인 계정 로그인/동의 → 앱으로 돌아오면 자동으로 토큰 발급
3. **발행하기** 버튼 → 실제 블로그에 글이 올라가고, 가능한 경우 글 링크가 표시됩니다.

네이버 앱 설정이 없으면 발행 버튼은 **연습(시뮬레이션)** 으로 동작해 앱은 계속 사용할 수 있습니다.

## 사진 자동 삽입 (imgbb)

네이버 블로그 글쓰기 API는 본문에 이미지를 직접 첨부하는 기능이 없습니다.
그래서 이 앱은 **사진을 imgbb에 올려 공개 URL을 받은 뒤, 블로그 본문에 `<img>` 태그로 삽입**합니다.

- **첫 사진**은 글 맨 위 **대표 이미지**로 고정(전체폭·둥근 모서리·그림자로 강조)되고
  바로 아래에 **캡션**(`▲ [매물명] 대표 사진`)이 붙습니다.
- **나머지 사진**은 AI가 본문에 넣은 `[📸 …]`/`[사진]` 안내 문구 자리에 순서대로 삽입됩니다.
  (안내 문구가 없으면 문단 사이사이에 고르게 분산, 사진이 남으면 글 끝에 이어 붙임)
- 사진이 없으면 `[📸 …]` 안내 문구는 자동으로 제거되어 깔끔한 글만 남습니다.
- 배치·스타일·캡션을 바꾸려면 `naver.build_contents_html()` 을 수정하면 됩니다.

imgbb 키가 없으면 사진 없이 글만 발행됩니다.

> ⚠️ 주의: imgbb에 올린 사진은 **외부 서비스에 공개적으로 저장**됩니다.
> 자체 서버나 다른 호스팅을 쓰려면 `images.py` 의 업로드 함수만 교체하면 됩니다.

## 파일 구성

| 파일 | 역할 |
|------|------|
| `app.py` | Streamlit UI + 전체 흐름(입력 → AI 글쓰기 → 확인 → 발행) |
| `naver.py` | 네이버 로그인(OAuth2), 블로그 글쓰기 API, 본문+사진 HTML 조립 |
| `images.py` | imgbb 이미지 업로드 |
| `requirements.txt` | 의존성 (`streamlit`, `google-genai`, `requests`) |
| `.streamlit/secrets.toml.example` | 키 설정 템플릿 |

## 한계 / 참고

- 연락처는 AI 본문에 중복 삽입되지 않도록, 프롬프트에서 "연락처는 직접 쓰지 말고 CTA로 마무리"하게
  지시하고 시스템이 실제 연락처 블록만 자동으로 덧붙입니다.
- 네이버 블로그 글쓰기 API는 앱별 권한 승인이 필요하며 정책에 따라 이용 조건이 달라질 수 있습니다.
  실제 발행 전에는 등록한 계정으로 테스트해 보시길 권장합니다.
- `google-genai` 임포트는 "글 생성" 시점에만 지연 로딩되므로, 키가 없어도 앱 화면은 정상적으로 뜹니다.
