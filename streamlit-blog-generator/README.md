# ✨ 짐픽 프리미엄 부동산 블로그 생성기 (Streamlit)

공인중개사를 위한 모바일 친화적 AI 블로그 초안 생성기입니다.
매물 사진과 기본 정보만 넣으면 **Google Gemini**가 사진까지 분석해
감성적이고 상세한 네이버 블로그 포스팅 초안을 만들어 줍니다.
완성된 글을 복사해 네이버 블로그에 붙여넣고, 안내 문구(`[📸 …]`) 자리에
사진만 채우면 끝입니다.

> 참고: 이 앱은 메인 React(JIMPICK) 앱과는 별개로 동작하는 독립 Streamlit 앱입니다.

## 사용 흐름

1. **Gemini API 키** 입력 (상단)
2. **중개사무소 정보** 입력 (상호명 · 담당자 · 연락처 · 사무소 주소) → 글 하단에 자동 삽입
3. **매물 정보** 입력 (이름 · 가격/조건 · 추가 강조 포인트)
4. **매물 사진 업로드** (여러 장, AI가 사진을 분석해 반영)
5. **"고품격 블로그 글 뚝딱 완성하기"** 버튼 → 완성된 글 확인
6. 글을 복사해 네이버 블로그에 붙여넣고, `[📸 …]` 위치에 사진을 채워 발행

## 실행 방법

```bash
cd streamlit-blog-generator
pip install -r requirements.txt
streamlit run app.py
```

실행하면 브라우저에서 `http://localhost:8501` 로 열립니다.

## Gemini API 키

[Google AI Studio](https://aistudio.google.com/apikey)에서 무료로 발급받아,
앱 상단의 **"🔑 Gemini API 키 입력"** 칸에 붙여넣으면 됩니다.
사용 모델은 `app.py`의 `genai.GenerativeModel('gemini-2.0-flash')` 에서 바꿀 수 있습니다.

## 특징

- 🌸 화사한 프리미엄 핑크 디자인, 모바일 친화적 레이아웃
- 📸 업로드한 사진을 AI가 직접 분석해 공간별 장점을 글에 반영 (멀티모달)
- 🖼️ 본문 중간에 `[📸 여기에 거실 사진 삽입]` 안내 문구를 배치 — 복붙 후 사진만 채우면 됩니다
- 📞 중개사무소 정보(상호명·담당자·연락처·주소)를 글 하단에 자동 삽입
