# JIMPICK: Smart Moving Quotes

[프로젝트명]

JIMPICK 7.0 — AI 이사 견적 앱



[역할]

당신은 대한민국 최고 수준의 모바일 앱 UI/UX 디자이너이자

React + TypeScript + Tailwind CSS 전문 풀스택 개발자입니다.



내가 첨부한 JIMPICK 7.0 디자인 이미지를 기준으로

화면 구성, 카드 크기, 여백, 버튼, 색상, 그림자, 글씨 크기,

아이콘 위치를 최대한 동일하게 구현해 주세요.



단순한 디자인 시안이 아니라,

모든 버튼과 입력창이 실제로 작동하는 프로그램으로 제작해 주세요.



──────────────────────────────



[중요 제작 기준]



1. 첨부된 이미지를 가장 우선적인 디자인 기준으로 사용한다.

2. 모바일 앱 형태로 제작한다.

3. 기본 화면 크기는 세로형 스마트폰 390px~430px에 최적화한다.

4. 태블릿과 PC에서는 모바일 화면이 중앙에 정렬되도록 한다.

5. React + TypeScript + Tailwind CSS를 사용한다.

6. 모든 화면은 하나의 프로젝트 안에서 연결한다.

7. 다음 버튼을 누르면 다음 단계 화면으로 이동해야 한다.

8. 이전 버튼을 누르면 입력한 내용을 유지한 상태로 이전 화면으로 돌아간다.

9. 새로고침해도 작성 중인 견적 데이터가 사라지지 않도록 localStorage를 사용한다.

10. 처음에는 실제 서버 없이 테스트 가능한 완성형 데모로 제작한다.

11. 모든 버튼, 수량 조절, 방 추가, 방 삭제, 차량 선택, 견적 계산이 실제 작동해야 한다.

12. 비어 있는 버튼이나 작동하지 않는 장식용 요소를 만들지 않는다.

13. 글씨와 버튼은 50~60대 사용자도 쉽게 사용할 수 있도록 크게 만든다.

14. 복잡한 전문 용어 대신 쉬운 한국어를 사용한다.

15. 이미지에 없는 불필요한 기능은 임의로 추가하지 않는다.
