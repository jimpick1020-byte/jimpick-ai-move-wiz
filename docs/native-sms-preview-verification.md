# 사전정보·방문 통신사 문자와 미리보기 검증 (2026-10-15 KST)

## 적용 범위
- 사전정보 문자: `[짐픽 사전정보 요청]` + 빈 줄 + `방문 전 이름,이사 날짜, 주소, 작업 조건, 평수를 입력해 주세요.` + 빈 줄 + 사전정보 보안 링크 한 개.
- 방문 문자: `[짐픽 방문견적 안내]` + 빈 줄 + `아래 링크를 눌러 방문 날짜와 시간을 확인해 주세요.` + 빈 줄 + 방문 보안 링크 한 개.
- 두 버튼 모두 국내 휴대전화 번호의 구분 기호를 제거하고 `sms:{번호}?body={URL 인코딩된 본문}`으로 연결. 공용 동기 잠금과 2초 재열기 방지 사용.
- 기존 `sendIntakeSms`는 이름을 유지하되 통신사 문자 준비만 반환. 알리고 호출·발송 이력 추가·발송 완료 저장 제거. 기존 문자 이력은 변경하지 않음.
- 방문 준비는 기존 `visit_sms_opened_at`만 기록하며 `visit_sms_confirmed_at`는 저장하지 않음. 별도 사장님 확인 동작은 유지.
- 새 링크에 `?preview=v2` 적용. 토큰 경로·조회·기존 링크 유효성은 그대로 유지.
- 새 이미지 두 개: `intake-preview-v2.webp`, `visit-preview-v2.webp`. 1200×630, 각각 40,002 / 49,284바이트. 자동차·글자·로고 없음. 중앙 캐릭터 전체와 가로 배경 확인.

## 수정 파일
- `src/lib/intake.ts`: 두 짧은 문자 생성기
- `src/lib/intake-sms.ts`: 공용 문자 URI와 중복 열기 방지
- `src/lib/intake.functions.ts`: 업체 범위 문자 준비, 알리고 발송 경로 제거
- `src/lib/intake.server.ts`: 미리보기 버전값
- `src/components/jimpick/IntakePanel.tsx`: 두 문자 버튼 연결과 동기 잠금
- `src/routes/intake.$token.tsx`, `src/routes/visit.$token.tsx`: 초기 HTML Open Graph / Twitter 이미지·제목·설명·크기
- `src/routes/__root.tsx`: 모든 페이지에 적용되던 기존 자동차 공유 이미지 제거
- `src/assets/message-previews/intake-preview-v2.webp.asset.json`, `visit-preview-v2.webp.asset.json`: 새 공개 이미지
- `src/lib/intake-sms.test.ts`, `intake.test.ts`, `intake-visit.test.ts`: 규칙 시험
- `src/lib/AGENTS.md`, `roadmap.md`: 구조 규칙과 진행 상태

## 저장 구조
새 테이블·열·RPC·마이그레이션 없음. 기존 `intake_requests`와 보안 토큰 재사용. 기존 고객·요청·견적·계약·결제·문자 기록을 삭제하거나 초기화하지 않음. 시험에서 이번에 만든 번호 `010-0000-0015`의 별도 요청만 사용.

## 실제 수행한 시험
환경: 현재 요청자 계정으로 로그인한 Chromium, 384×854 휴대폰 크기. 삼성 실물 기기가 아님.
