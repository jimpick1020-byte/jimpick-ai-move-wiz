# 공통 품목 이미지 잘림 수정 결과

## 수정 내용과 파일
- 공통 카드: `src/components/jimpick/ItemListLayer.tsx`의 `ItemPickerCard`. 짐픽과 고객 링크가 모두 같은 카드 사용. 모바일 3열과 192px 카드 높이 유지. 그림은 카드 너비에 따라 줄어드는 정사각형이며 이름은 아래 40px 영역에 최대 두 줄. 수량 버튼은 선택 카드에서만 아래에 표시.
- 공통 CSS: `src/styles.css`. `.jp-picker-art`에 `aspect-ratio: 1`, `padding: 8px`; 내부 이미지에 `width: 100%`, `height: 100%`, `object-fit: contain`, `object-position: center`, `margin: 0` 적용.
- 그림 표시: `src/lib/jimpick-icon3d.tsx`. 품목 카드의 cutout 경로에서 `transform: scale(1)`까지 제거해 실제 계산값 `none`; 해당 그림 래퍼의 `overflow-hidden` 제거. 다른 화면의 기존 아이콘 확대 기능은 변경하지 않음.
- 기존 검은 배경·흰 글씨·테두리 토큰 유지. 원본 이미지 파일과 품목/선택/견적 데이터 변경·삭제 없음.
- `src/lib/AGENTS.md`, `roadmap.md`: 공용 그림 표시 규칙과 시험 상태 기록.

## 직접 화면 시험
Chromium에서 휴대폰 너비 384px, 높이 844px로 실제 업체 인증 세션과 기존 고객 사전정보 링크를 열었습니다. 새로운 임시 고객 화면은 만들지 않았습니다. 업체 화면은 입력 내용 변경 없이 기존 화면 전환 기능으로 품목 단계만 열었습니다. 고객 화면은 기존 입력값으로 단계 이동하고 품목 선택·수정·제출은 하지 않았습니다.

| 항목 | 짐픽 | 고객 사전정보 |
|---|---|---|
| 침대 | 6종 개별 카드 사진 확인 | 6종 개별 카드 사진 확인 |
| 식탁 | 6종 개별 카드 사진 확인 | 6종 개별 카드 사진 확인 |
| 카드 가로×세로 | 모두 112×192px | 모두 112×192px |
| 정사각 그림 영역 | 모두 98×98px | 모두 98×98px |
| 실제 img 칸 | 모두 82×82px | 모두 82×82px |
| 안전 여백 | 위·아래·좌·우 모두 8px | 위·아래·좌·우 모두 8px |

침대·식탁의 동일 ID 표본(bedq, bedking, two-seat-dining-table-01, six-seat-dining-table-01, marbletable, table, table6)에서도 카드·그림 칸 크기가 일치했습니다. 두 화면의 품목 목록 구성 차이는 이번 요청 범위가 아니므로 변경하지 않았습니다.

## 한계와 별도 확인사항
- 실제 Samsung Browser/Chrome 휴대폰 기기를 조작한 것은 아니며, 휴대폰 너비의 Chromium 화면 시험입니다.
- 일부 기존 이미지에는 앞서 적용된 밝은 배경 제거 처리로 물체의 밝은 부분이 빠져 보입니다. 이는 카드 가장자리 잘림과 다른 현상이며 이번에는 원본/배경 제거 로직을 변경하지 않았습니다.
- 기존 김호영 확정 요청의 ‘견적 초안으로 이동’은 `견적 초안을 찾지 못했습니다.`를 표시했습니다. 이번 그림 수정과 무관한 기존 초안 조회 문제로, 자료 복구·변경은 하지 않았습니다.
- 회귀 시험: item-cutout / room-item-state 9개 통과, 0개 실패. 최신 자동 빌드 로그 `build OK` 확인.
