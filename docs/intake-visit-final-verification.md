## 변경한 저장 항목과 함수
- 새 테이블은 만들지 않았습니다. 방문은 기존 `intake_requests`의 요청 ID를 방문 ID로 사용합니다.
- `intake_requests`: `deleted_at`, `visit_completed_at` 추가. 기존 `visit_date`, `visit_time`, `visit_status`, `visit_memo` 재사용.
- `estimate_drafts`: 기존 삭제 표시를 사용합니다. 정식 견적이 있는 경우 그 초안은 보존합니다.
- `estimate_terms`, `deposit_records`: 예약금 확인 변경 시 연결 방문 완료 트리거 추가. 기존 기록의 일괄 수정·삭제는 하지 않았습니다.
- `has_confirmed_calendar_deposit`: 실제 양수 예약금, 입금 확인자·확인시간, 최신 정식 견적의 예약금 상태 확인.
- `complete_linked_intake_visit`: 같은 업체와 견적 ID의 활성 방문만 completed로 전환하고 완료시간 저장.
- `guard_completed_intake_visit`: 완료 방문의 재등장 방지.
- `delete_intake_request`: 로그인한 업체의 요청 ID로 잠금 후 요청 삭제 표시·방문 날짜/시간 제거·미전환 초안 삭제 표시를 한 트랜잭션에서 처리. 정식 견적·계약·입금·문자 기록 보존.
- 요청의 `company_id`와 `estimate_id`, 정식 견적/입금의 기존 소유자 `user_id`를 대응하여 조회합니다. 이름·날짜로 자료를 연결하지 않습니다.
