# 은행 잔금 직접 확인 (2026-10-19)

- 사용자가 선택한 직접 확인 방식: 잔금 기록 추가 버튼 제거, 계좌이체 선택 후 실제 은행 문자와 금액을 확인하고 잔금 입금 확인 클릭.
- 휴대전화 은행 문자 자동 읽기는 지원하지 않는다. 자동 주황 테두리는 실제 미확인 계좌 입금 기록이 있을 때만 표시하며, 기록 없는 고객은 입금한 것으로 표시하지 않는다.
- 별도 security-invoker RPC는 인증·업체 소유·견적 잠금·명시적 확인·화면에 표시된 잔금 일치·취소/환불 거부를 확인한다. 기존 미확인 잔금 기록이 있으면 그 기록의 확인을 요구한다.
- 직접 확인은 확인된 계좌이체 잔금 기록을 만들고 기존 완료 RPC에 위임한다. 입금자·실제 입금 시각은 임의 생성하지 않고 확인 담당자·시각과 직접 확인 사유를 보존한다. 총액·예약금은 변경하지 않고 문자 발송 경로를 호출하지 않는다.
- 요청자 로그인 상태의 384×681 화면에서 별도 시험 견적을 사용했다. 총액 1,030,000원, 예약금 80,000원, 잔금 950,000원. 잔금 추가 버튼 없음과 확인 안내를 확인했다.
- 잔금 입금 확인 클릭 후 bank_transfer/completed, 잔금 950,000원 및 확인 담당자·시각 저장, 완료 보관함 이동과 새로고침 후 유지 확인. 중복 확인은 이미 완료로 반환하고 기록을 추가하지 않았다.
- 확인 기록의 실제 입금 시각과 문자 발송 시각 NULL 확인. 화면 오류 0건. 31개 결제 규칙 시험 통과, 자동 검사 build OK.
- 생성한 시험 입금과 견적만 제거했다. 이다건 고객의 실제 잔금을 대신 확인하지 않았다. 실제 은행 자동 수신·실물 휴대전화 문자는 미시험이며 자동 수신 기능은 추가하지 않았다.
