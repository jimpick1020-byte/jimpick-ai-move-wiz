## 실제 확인
로그인한 Chromium 휴대폰 크기 384×854에서 새 시험 견적만 사용.
- 3·4·5단계 캐릭터 표시 크기 모두 168×168px, 이미지 정상 로드.
- 직접 선택의 큰 캐릭터가 평수·방 카드 위 별도 영역에 표시됨. 뒤로는 AI 촬영 화면으로 복귀.
- AI 안내 영역이 사진 미리보기 위에 위치하며 겹치지 않음. 촬영·다음 방·앨범 버튼 표시 확인.
- 다음 방 촬영 버튼으로 안방→작은방 이동. 앨범 버튼으로 파일 선택창 열림 확인(사진 업로드·분석 실행 안 함).
- 남자·주방 모두 0명에서 회색 테두리, 1명에서 주황색 표시. 두 카드 동시 표시 확인.
- 차량·남자·주방 카드의 계산된 테두리 색상·두께·모서리·그림자 동일: rgb(255,138,0), 1px, 18px, 2px 주황 외곽 그림자.
- 감소 버튼으로 0명이 되면 즉시 주황 표시 해제. 증가하면 즉시 복귀.
- 새로고침 후 남자 1명·주방 1명 복원, 화면 재진입 확인. Cloud의 해당 시험 초안에서도 workers=1, kitchenStaff=1, truck1t=1 읽기 확인.
- 견적 결과에서 남자 1명·주방 1명, 1톤 1대, 250,000원 표시 확인.
- 기존 계산은 작업 인원 비용을 총액에 더하지 않음(기존 코드에 명시되어 있음). 이 계산식을 변경하지 않았으며, 인원별 비용의 별도 저장은 이번 시험에서 확인하지 않음. 임시 초안의 total=0은 기존 초안 저장값이며 결과 화면은 기존 계산식으로 250,000원을 표시. 견적 완료 저장은 하지 않음.
- 기존 room-item-state, scan-rules, worker-contact 시험 23개 통과. 변경 후 build OK.

## 미확인
- 실물 휴대폰 카메라 실행·촬영·사진 분석, 실제 삼성 인터넷.
- 정식 견적 완료 저장, 문자·예약·결제 재시험(해당 기능 미변경).
- 작업 인원 비용의 별도 저장·정식 견적 총액 저장.

시험 과정에 새 작성 중 견적이 생성되었으며 기존 고객 견적은 수정·삭제하지 않음.
