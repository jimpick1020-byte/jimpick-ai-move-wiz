# 잔금 직접 입금 확인 검증 (2026-10-19)

- 미확인 계좌입금 기록은 접힌 상태에서도 펼쳐 표시한다. 입력 영역은 입금 기록 추가를 선택할 때만 표시한다.
- 기존 기록의 잔금 입금 확인 버튼은 DepositPanel의 잠금 확인 경로를 그대로 사용한다. 서버 처리와 현금·카드 확인은 변경하지 않았다.
- 요청자 인증 세션, 384×681 화면에서 시험용 세 견적을 사용했다. 잔금 950,000원 등록 후 문자 입력 영역이 닫힌 상태에서 잔금 입금 확인만 눌러 완료했다.
- 계좌이체 주황 4px 테두리, 완료 보관함 이동과 새로고침 후 유지, 현금·카드 각각 완료를 확인했다.
- 총액 1,000,000원, 예약금 50,000원, 잔금 950,000원 유지 및 확인 시각·담당자 저장을 확인했다.
- 기존 계약·입금·발송·사용량·전날 예약 5종 조회값 불변. 문자 요청 0건, 화면 오류 0건. 생성한 시험용 기록만 정리했다.
- 기존 결제 규칙 26개 시험 통과. 실제 휴대전화 은행 문자 자동 읽기는 지원하지 않으며 저장된 입금 기록이 없으면 먼저 등록해야 한다.
