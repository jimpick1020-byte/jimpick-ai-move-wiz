# 전날 문자 재발송과 주소 건물명 확인

- 실제 업체 로그인 상태에서 저장된 전날 문자 예약을 읽어 ReminderPanel을 384×681 화면에 표시했다.
- 유효한 보안 링크가 있는 실제 예약에서 「한 번 더 발송」으로 문자 안내문·받는 번호·발송/취소 선택창을 확인했다. 기존 삭제 링크 기록은 내용 조회 실패로 표시하고 발송하지 않았다.
- 「취소」 후 확인창이 닫혔다. 미리보기 함수는 SELECT만 실행하고 발송 함수·사용량 예약을 호출하지 않는다.
- 실제 카카오 검색 「대구 북구 검단로 115」에 「유성청구아파트」 이름이 반환되고 저장용 주소가 「대구 북구 검단로 115 (유성청구아파트)」로 조합됐다.
- 아파트·빌라·원룸·없는 이름·중복 이름 규칙과 기존 고객 조건/문자 규칙 총 13개 시험 통과. 최신 build OK.
- 실제 고객에게 재발송하지 않았다. 양쪽 주소의 전체 입력·저장·새로고침 과정 및 실물 기기 발송은 미검증. 기존 상세주소와 좌표 콜백은 변경하지 않았다.
