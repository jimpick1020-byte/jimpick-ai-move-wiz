# 고객 견적서 문구와 예약 상태 수정

## 변경 범위
- 고객용 견적서 상단과 견적서 내부에서 `JIMPICK` 문구를 제거하고 업체 상호만 표시합니다.
- 견적서 안내 문자 본문의 `[JIMPICK 짐픽]` 문구를 제거합니다.
- 기존 고객·견적·결제 기록은 변경하거나 초기화하지 않습니다.

## 상태 기준
- 견적 발송만 완료: `견적 안내`
- 고객 약관 동의 완료, 예약금 미확인: `예약 요청` 또는 입금 안내 단계에서는 `입금 대기`
- 실제 예약금 확인: `예약 확정`
- 전액 결제 완료: `결제 완료`
- 고객 동의 동작은 예약 확정이 아니라 예약 요청으로 저장하며, 예약금 확인 전에는 어떤 화면에서도 확정으로 표시하지 않습니다.

## 구현
- 공통 예약 상태 계산 함수를 만들고 고객 견적서, 견적 내역, 고객 관리, 계약 달력, 견적 현황에서 같은 결제·동의 기준을 사용합니다.
- 고객 동의 버튼과 완료 안내를 `예약 요청` 표현으로 변경합니다.
- 달력은 실제 예약금 확인된 진행 계약과 결제 완료 계약만 유지합니다.
- 고객 동의 저장 함수와 관련 알림 문구를 예약 요청 의미로 바꾸되 기존 동의 기록과 결제 기록은 보존합니다.
- 필요한 경우 기존 `reservation_status` 값은 읽기 호환성을 유지하면서 새 동의부터 `requested`로 저장하도록 데이터베이스 함수를 안전하게 갱신합니다.

## 확인
- 고객용 견적서와 예약금 화면에서 업체 상호, 견적번호, 상태 배지를 확인합니다.
- 동의 전 → 동의 후 → 예약금 확인 → 전액 결제 단계별 문구를 확인합니다.
- 견적 내역·고객 관리·달력·견적 현황에서 같은 상태 기준이 적용되는지 확인합니다.
- 문자 본문에서 `[JIMPICK 짐픽]`이 제거되고 기존 고객별 링크와 문의번호가 유지되는지 확인합니다.
