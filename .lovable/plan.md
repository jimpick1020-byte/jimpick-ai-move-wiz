# 일반 사장님 AI·음성 시험 기능 완전 차단 계획

## 목표
- 일반 사장님·업체 관리자·직원에게 AI 집 안 스캔, 음성 자동입력, 사진·동영상 자동인식 화면과 연결을 전혀 렌더링하지 않습니다.
- 기존 AI 코드와 저장 데이터는 보존하고, 최고관리자가 각 시험 기능을 켠 경우에만 사용할 수 있게 합니다.
- 「목록에 없는 품목 추가」와 품목 한 개의 사진 등록·3D 생성은 일반 사장님에게 그대로 유지합니다.

## 구현
1. **안전한 시험 기능 설정**
   - 음성 품목입력, AI 사진 인식, AI 동영상 인식의 세 설정을 기본 OFF로 저장합니다.
   - 조회와 변경 모두 로그인 사용자의 최고관리자 역할을 서버에서 확인합니다.
   - 일반 계정은 설정을 읽거나 바꿀 수 없도록 데이터 접근 규칙을 적용합니다.

2. **화면·단계·복원 경로 차단**
   - 첫 화면, 메뉴, 설정, 안내 문구에서 역할과 개별 설정을 모두 만족할 때만 시험 기능을 렌더링합니다.
   - 일반 견적 흐름은 차량 선택 뒤 방별 품목 화면으로 바로 이동하도록 고칩니다.
   - 뒤로가기, 새로고침, 임시저장 복원, 과거 화면 기록이 `ai`를 가리키면 방별 품목 화면으로 자동 보정합니다.
   - AI 화면 컴포넌트 자체도 권한 확인 전에는 렌더링하지 않고, 허용되지 않으면 방별 품목 화면으로 이동합니다.

3. **서버 권한 차단**
   - 음성 해석과 사진·동영상 자동인식 서버 기능에 최고관리자 역할과 해당 시험 설정을 모두 검사하는 보호 장치를 추가합니다.
   - 화면을 우회해 직접 호출해도 일반 계정 요청은 거부합니다.
   - 품목 한 개 사진으로 3D 아이콘을 만드는 기존 기능은 이 시험 기능과 분리해 계속 허용합니다.

4. **설정 화면과 캐시 갱신**
   - 최고관리자 전용 화면에 세 개의 시험 기능 스위치를 추가하고 변경 즉시 화면에 반영합니다.
   - 서비스워커 캐시 이름·업데이트 식별자를 갱신하고, 새 버전 확인 시 이전 HTML/스크립트가 다시 덮어쓰지 않도록 보강합니다.
   - 로그인·사용자 데이터와 작성 중 견적은 삭제하지 않습니다.

5. **검증**
   - 전체 검색으로 모바일·PC·메뉴·도움말·단계 이동에 남은 노출을 다시 확인합니다.
   - 타입검사, 테스트, 현재 빌드 상태를 확인합니다.
   - 390px에서 일반 사장님과 최고관리자 OFF/ON을 각각 확인하고, 직접 서버 호출도 역할별로 검사합니다.
   - 가능한 실제 계정으로 새 견적, 뒤로가기, 새로고침, 직접 접근, 「목록에 없는 품목 추가」 유지와 새 품목 보존을 확인합니다.

## 기술 세부사항
- 기존 단일 `/` 화면 상태 구조에는 별도 AI 주소가 없으므로, 화면 상태 전환·브라우저 방문기록·저장 상태를 모두 같은 권한 함수로 정규화합니다.
- 설정은 별도 보호 테이블과 서버 함수로 관리하고, 클라이언트가 보낸 역할 값은 신뢰하지 않습니다.
- 기존 고객·견적·품목·계약·문자·결제·스토리지 데이터에는 삭제·초기화 작업을 하지 않습니다.
