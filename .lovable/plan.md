# 계약 달력 표시 겹침 수정

## 변경 범위
- 첫 화면 계약 달력의 날짜 칸과 선택 날짜 계약 목록만 수정합니다.
- 기존 고객·견적·계약 데이터, 조회 조건, 다른 화면은 변경하지 않습니다.

## 구현
- 날짜 칸 높이를 늘리고 계약 건수는 날짜 아래 중앙의 큰 배지로 표시합니다.
- 진행 계약이 하나라도 있으면 파란색 `N건` 또는 `총 N건`, 완료 계약만 있으면 민트색 `완료 N건`으로 표시합니다.
- 손 없는 날은 우측 상단의 작은 코랄색 `손` 표시로 옮기고 계약 배지보다 낮은 표시 계층과 `pointer-events: none`을 적용합니다.
- 날짜 전체 버튼은 계속 클릭 가능하게 유지합니다.
- 선택한 날짜의 계약은 이사시간순으로 정렬하고 고객명·시간·상태·견적서 보기 버튼을 모두 표시합니다.
- 견적서 열기는 기존 `estimate_id` 연결 방식을 그대로 사용합니다.

## 확인
- 390px 화면에서 계약과 손 없는 날이 겹치는 날짜, 계약 2건 이상인 날짜를 확인합니다.
- 두 배지가 겹치거나 잘리지 않고 가로 스크롤이 생기지 않는지 확인합니다.
- 날짜 선택과 실제 견적서 연결, 화면 오류 여부를 확인합니다.
