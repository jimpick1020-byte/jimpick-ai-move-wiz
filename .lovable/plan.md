# 알리고 -102 인증 오류 수정

## 변경 사항
- `send-estimate-sms`가 서버 비밀값 `ALIGO_API_KEY`를 읽을 때 앞뒤 공백과 줄바꿈을 제거합니다.
- 고정된 `user_id=jimpick1020`, `sender=01075662542`, 기존 수신번호와 문자 내용은 그대로 유지합니다.
- API Key 원문은 화면·응답·로그에 노출하지 않습니다.
- 수정한 `send-estimate-sms` 함수만 다시 배포합니다.

## 확인
- 배포 로그에서 새 함수가 시작됐는지 확인합니다.
- 전송값의 실제 비밀내용 대신 API Key 길이와 고정 `user_id`/`sender` 적용 여부만 안전하게 검증합니다.
- 기존 견적서·고객·문자발송 데이터는 변경하거나 삭제하지 않습니다.

## 기술 세부사항
- `Deno.env.get("ALIGO_API_KEY")?.trim()`으로 보이지 않는 후행 문자를 제거한 뒤 `URLSearchParams`의 `key`에 사용합니다.
- 알리고 응답의 `result_code >= 1` 성공 판정과 실패 원문 표시는 유지합니다.
