# 카카오톡 공유와 품목 분류 색상 수정

## 변경 내용
- 직원 공유창을 열 때 보안 링크와 카카오 SDK를 먼저 준비하고, `카카오톡 열기` 클릭 순간 공유창을 바로 호출해 브라우저 차단을 피합니다.
- 공유 준비 실패 시 성공 안내를 표시하지 않고 실제 오류를 보여줍니다.
- 직전 단계별 색상이 모든 파란 글자를 일괄 변경하던 규칙을 제거해 기존 글자색으로 되돌립니다.
- 고객명, 연락처, 이사 종류, 작업 조건, 작업 인원 등 요청된 항목명에만 단계별 색상을 적용합니다.
- 품목의 `가전·가구·주방·생활용품·레저·기타` 분류는 각각 구분되는 고유 색상을 적용합니다.

## 확인
- 휴대폰 화면에서 카카오톡 열기 동작과 실패 안내를 확인합니다.
- 3·4단계 큰 글씨와 출발지·도착지 구분 간격은 유지합니다.
- 품목 분류 외 일반 글자가 기존 색으로 돌아왔는지 확인합니다.
