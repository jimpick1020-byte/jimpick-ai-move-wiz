# 첫 화면 계약 일정 달력

## 변경 범위
- 첫 화면의 `최근 작업` 카드만 제거하고 같은 자리에 모바일 계약 일정 달력을 배치합니다.
- 고객 현황, 견적 현황, 하단 메뉴와 다른 화면은 변경하지 않습니다.
- 기존 고객·견적·계약 데이터는 읽기만 하며 삭제·초기화하지 않습니다.

## 구현
- 기존 업체별 계약 조회를 재사용해 로그인한 업체의 `estimate_id`별 최신 계약만 표시합니다.
- 예약금 완료 또는 확정된 진행 계약과 결제완료 계약만 포함하고, 미결제·임시·취소·삭제 건은 제외합니다.
- 진행 계약은 파란 점, 결제완료 계약은 민트 점으로 표시하며 같은 날 여러 건이면 건수를 함께 표시합니다.
- 날짜 선택 시 고객명, 이사시간, 출발지 요약, 계약 상태를 보여주고 실제 견적서를 열 수 있게 합니다.
- 이전달·다음달 이동, 오늘 표시를 지원합니다.
- `korean-lunar-calendar`로 각 날짜를 한국 음력으로 변환해 음력 일자 끝자리가 9 또는 0이면 코랄색 `손` 배지를 표시합니다.

## 기술 세부사항
- 인증된 서버 조회는 현재 로그인 사용자의 업체 범위로 제한되고 기존 행 보안 정책을 그대로 적용합니다.
- 달력 전용 표시 컴포넌트를 분리해 기존 견적 작성 단계의 달력 동작에는 영향을 주지 않습니다.
- 계약을 누르면 기기 저장본이 있으면 해당 `estimate_id`를 열고, 없으면 서버 계약 스냅샷을 불러옵니다.

## 확인
- 390px 모바일 화면에서 가로 스크롤과 글자 겹침을 확인합니다.
- 실제 로그인 데이터로 날짜 선택, 같은 날 여러 계약 건수, 견적서 열기, 이전·다음달, 오늘, 손 없는 날 계산을 확인합니다.
