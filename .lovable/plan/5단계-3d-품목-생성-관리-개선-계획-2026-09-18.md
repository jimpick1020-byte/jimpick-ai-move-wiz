# 5단계 3D 품목 생성·관리 개선 계획

## 목표
- 기존 견적과 품목 데이터를 유지하면서, 생성 품목의 한글 이름·분류·이미지·크기 정보를 안전하게 저장합니다.
- 검색과 생성 흐름을 하나로 정리하고, 현재 열린 공간에 즉시 담기며 같은 종류끼리 보이게 합니다.
- 시스템 품목과 업체 전용 품목을 함께 검사해 중복 생성을 막고, 카드 메뉴에서 이동·이름 수정·즐겨찾기·삭제를 제공합니다.

## 화면 변경
- 하단 `품목 직접 추가` 버튼과 검색 결과의 별도 `새 품목 추가` 버튼을 제거합니다.
- 3D 생성창에는 품목명, 5개 분류, 크기, 취소, 생성만 남깁니다. 수량은 1, 공간은 현재 열린 방으로 자동 적용합니다.
- 생성 성공 후 창을 닫고 선택 품목에 즉시 표시하며, 내부 ID·파일명·경로는 어떤 카드에도 이름으로 노출하지 않습니다.
- 카드의 점 3개 메뉴를 `자리 이동`, `품목명 수정`, `자주 담는 품목 등록/해제`, `품목 삭제`로 정리합니다.
- 모든 품목 카드의 실제 물체가 공통 정사각형 영역의 약 85%를 채우도록 투명 여백 보정을 강화합니다.

## 저장·복구
- 기존 `item_icons`에 표시 이름, 정규화 이름, 큰 분류, 세부 그룹, 크기, 저장 경로, 생성 여부, 생성 ID, 정렬값, 복구용 메타데이터를 안전하게 확장합니다.
- 현재 `name`, `norm_name`, `image_path`는 호환용으로 유지하고 기존 행·이미지를 삭제하지 않습니다.
- 잘못된 내부형 이름은 기존 prompt·metadata에서 원래 한글 이름을 복구합니다. 근거가 없으면 `이름 수정 필요`로 표시합니다.
- 이름 수정은 화면뿐 아니라 업체 소유 레코드에도 저장하여 새로고침과 다른 기기에서 유지합니다.

## 중복 차단과 자동 분류
- 공백·기호·대소문자·요청된 오타/동의어를 통일하는 공통 정규화 함수를 만듭니다.
- 생성 전 화면에서 시스템 기본품목, 자주 담는 품목, 현재 견적 품목, 업체 생성품목을 검사합니다.
- 서버에서도 업체 생성품목을 다시 검사하고 유일성 제약으로 동시 클릭 중복을 차단합니다.
- 중복이면 새 이미지를 만들지 않고 기존 아이콘을 현재 방에 1개 추가하거나 기존 수량을 1 올립니다.
- 공통 분류 함수가 청소기·침대·냉장고·세탁가전·식탁·수납장·TV 등 세부 그룹을 결정하며 생성품목은 해당 그룹 앞부분에 표시합니다.

## 기술 세부사항
- 생성 요청에는 화면에 보일 이름, 정규화 이름, 분류, 세부 그룹, 크기, 현재 공간을 명시적으로 전달합니다.
- AI 생성 결과는 정사각형 고해상도 이미지로 요청하고, 기존 공통 이미지 표시기가 실제 물체 영역을 측정해 확대합니다.
- 방 배치·수량·루베·차량 계산은 기존 견적 draft 구조와 자동 저장을 그대로 사용하므로 기존 계산식을 바꾸지 않습니다.
- 업체별 행 정책을 유지하며 다른 업체의 비공개 생성품목은 조회하지 않습니다.

## 검증
- 390px 화면에서 직접 품목 버튼 제거, 단순화된 생성창, 메뉴, 이미지 크기와 잘림을 확인합니다.
- 베란다에서 `로봇청소기`를 입력해 시스템 중복 재사용, 수량 증가, 자동 공간 배치와 청소기 그룹 정렬을 확인합니다.
- 별도의 미등록 품목 1건으로 실제 생성·저장·즉시 표시를 확인하고, 재입력 시 새 생성 없이 재사용되는지 확인합니다.
- 이름 수정과 자리 이동 후 새로고침하여 이름·이미지·분류·방 위치가 유지되는지 확인합니다.
- 기존 견적의 고객정보, 방별 품목, 수량, 루베와 차량 계산 값이 전후 동일한지 비교합니다.
